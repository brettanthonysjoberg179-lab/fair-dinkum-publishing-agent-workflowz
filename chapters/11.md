## The revenue engine

A book without sales is a hobby. The sales and funnel pipeline transforms a finished ebook into a revenue-generating product. This involves three components:

1. **Sales copy** — the words that convince people to buy
2. **Payment infrastructure** — the mechanism that processes transactions
3. **Fulfilment** — the delivery mechanism that gets the book to the customer

Each component is handled by a specialised agent, but they share a common goal: convert interest into payment into delivery with minimal friction.

## Sales copy generation

The Sales Copywriter produces five distinct copy assets, each with a different purpose and audience:

### 1. Landing page copy

The landing page is the primary sales tool. It follows the PASO framework:

- **Problem:** Agitate the reader's pain point
- **Agitate:** Show what's at stake if they don't solve it
- **Solution:** Introduce the ebook as the answer
- **Offer:** Present the specific deal (price, bonus, guarantee)

The copywriter generates:

- Headline (3 variants)
- Subheadline (2 variants)
- Problem section (300-400 words)
- Solution section (400-500 words)
- Benefits bullet list (8-12 items)
- Social proof placeholders (testimonials, download count, rating)
- Call-to-action button text (3 variants)
- FAQ section (5-8 questions with answers)
- Money-back guarantee text

### 2. Amazon description

Amazon has different constraints than a landing page. The copywriter adapts:

- HTML formatting allowed (bold, italics, bullet points)
- No external links
- Keyword-rich but natural-sounding
- Starts with a hook, not a headline
- Includes "Readers also bought" style cross-sells

### 3. Email sequence

A five-email launch sequence:

| Email | Timing | Purpose |
|-------|--------|---------|
| 1 | Day 0 | Launch announcement — the book is live |
| 2 | Day 2 | Problem agitation — why this matters to you |
| 3 | Day 4 | Social proof — what readers are saying |
| 4 | Day 6 | Objection handling — addressing hesitations |
| 5 | Day 8 | Last chance — price increase or bonus expiry |

Each email is 200-300 words, conversational, and includes a single clear CTA.

### 4. Social media snippets

Platform-specific posts for launch promotion:

- **Twitter/X:** 3 threads (10-15 tweets each) covering key insights from the book
- **LinkedIn:** 2 long-form posts positioning the author as an expert
- **Instagram:** 5 carousel post scripts with image descriptions
- **Facebook:** 3 posts for relevant groups and pages

### 5. Ad copy

Paid advertising variants:

- Facebook/Instagram: 5 headline variants, 5 primary text variants, 3 CTA variants
- Google Ads: 3 responsive search ad variants (15 headlines, 4 descriptions each)

## Webhook handling

The fulfilment pipeline is driven by Stripe webhooks. The webhook handler processes four event types:

### checkout.session.completed

Triggered when a customer completes checkout. Actions:

1. Verify the session metadata matches a valid project
2. Generate a tokenized download URL (72-hour expiry)
3. Send the download link to the customer's email
4. Create a customer record in the local database
5. Update the analytics agent with the sale event

### invoice.payment_succeeded

Triggered for subscription renewals. Actions:

1. Verify the subscription is still active
2. Generate a fresh download URL (new token, new expiry)
3. Send the updated download link
4. Record the recurring revenue event

### customer.subscription.updated

Triggered when a subscription changes (upgrade, downgrade, cancellation). Actions:

1. Update the customer record with new tier information
2. If upgraded: send new tier benefits and download links
3. If downgraded: adjust access permissions
4. If cancelled: schedule access revocation

### customer.subscription.deleted

Triggered when a subscription ends. Actions:

1. Revoke download access
2. Send a "we're sorry to see you go" email with re-offer
3. Record churn reason if available
4. Update analytics with churn event

## Tokenized download delivery

Download security is critical — you don't want purchased books floating around the internet. The system uses tokenized URLs:

### Token generation

```python
def generate_download_token(customer_id: str, project_id: str) -> str:
    payload = {
        "customer_id": customer_id,
        "project_id": project_id,
        "exp": datetime.utcnow() + timedelta(hours=72),
        "jti": str(uuid4())  # unique token ID for revocation
    }
    return jwt.encode(payload, SECRET_KEY, algorithm="HS256")
```

### Token validation

```python
def validate_download_token(token: str) -> DownloadClaim:
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        if payload["exp"] < datetime.utcnow():
            raise TokenExpiredError()
        if is_revoked(payload["jti"]):
            raise TokenRevokedError()
        return DownloadClaim(**payload)
    except jwt.InvalidTokenError:
        raise InvalidTokenError()
```

### Delivery flow

1. Customer clicks download link in email
2. Server validates the token
3. If valid: serve the file with appropriate headers (Content-Type, Content-Disposition)
4. If expired: show a "link expired" page with a request-new-link option
5. If revoked: show an "access revoked" page with support contact

## Funnel analytics

The funnel agent tracks the complete customer journey:

```
Impression → Landing page view → Add to cart → Checkout started → Payment completed → Download
```

Each stage is tracked with:

- **Count:** How many people reached this stage
- **Conversion rate:** Percentage who moved to the next stage
- **Drop-off rate:** Percentage who left at this stage
- **Time to conversion:** How long from first impression to purchase

This data feeds directly into the Analytics Agent's optimisation recommendations.

- Sales copy is five assets: landing page, Amazon, email sequence, social, ads.
- Stripe products match the three-tier model: single, weekly, monthly.
- Webhooks drive the entire fulfilment pipeline.
- Tokenized downloads with 72-hour expiry balance security with usability.
- Funnel analytics track every stage from impression to download.
