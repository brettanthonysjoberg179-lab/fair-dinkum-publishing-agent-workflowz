*SQLAlchemy models, Alembic migrations, the repository pattern, and local-first data strategy.*

## Why you need a database

Agents generate data. Lots of it. The Market Researcher produces keyword lists and competitor summaries. The Opportunity Scorer produces ranked niches with scores. The Outline Architect produces hierarchical structures. The Manuscript Author produces chapters and sections. The Production Lead produces final files. The Funnel Builder produces Stripe checkout URLs.

If you store this data in plain text files, you lose the ability to query, relate, and version it. You can’t ask “show me all projects where the opportunity score was above 80” or “which chapters belong to project X?” without writing custom parsers.

A database solves this. It gives you:
- **Structured storage:** Every project, outline, manuscript, and artifact has a defined schema.
- **Query power:** You can filter, sort, and join data across projects.
- **Version control:** Alembic tracks schema changes so you can migrate between versions.
- **Concurrency:** Multiple agents can read and write safely without corrupting data.

The Fair Dinkum Publishing workforce uses SQLAlchemy as the ORM and Alembic for migrations. The default backend is SQLite — a single file database that needs no server. When you outgrow SQLite, you switch to PostgreSQL by changing one environment variable.

---

## The entity model

Before writing code, let’s map the entities and their relationships.

**Project**
The central entity. Every ebook starts as a project. A project has a title, niche, status, positioning data, outline, manuscript paths, cover paths, ebook paths, sales copy paths, Stripe payment links, and Obsidian note paths.

**OpportunityScore**
Attached to a project. Stores the ranked niche list, demand scores, competition scores, monetisation fit scores, and production effort estimates.

**Outline / Chapter**
An outline belongs to a project. An outline contains multiple chapters. Each chapter has a title, summary, estimated word count, and ordering.

**Manuscript / Section**
A manuscript belongs to a project. A manuscript contains multiple sections. Each section maps to a chapter or subsection and contains the actual prose in Markdown.

**Artifact**
A generic container for any generated file: covers, sales copy, ebook files, research notes. Each artifact has a type, file path, MIME type, and metadata.

The relationships look like this:

```
Project 1 ──< OpportunityScore
Project 1 ──< Outline >── Chapter
Project 1 ──< Manuscript >── Section
Project 1 ──< Artifact
```

One project has one opportunity score, one outline, one manuscript, and many artifacts.

## SQLAlchemy setup

Create `app/core/database.py`:

```python
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker, Session
import os
from dotenv import load_dotenv

load_dotenv()

DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./data/app.db")

# SQLite needs check_same_thread=False for FastAPI's threading model
connect_args = {"check_same_thread": False} if "sqlite" in DATABASE_URL else {}

engine = create_engine(DATABASE_URL, connect_args=connect_args)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db() -> Session:
    """FastAPI dependency that provides a database session."""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

This file does three things:
1. Reads `DATABASE_URL` from the environment, defaulting to SQLite.
2. Creates the SQLAlchemy engine and session factory.
3. Provides a `get_db()` generator for FastAPI dependency injection.

The `check_same_thread=False` flag is specific to SQLite. It allows FastAPI to share the connection across threads. PostgreSQL doesn’t need it.

## The repository layer

Direct ORM usage in agents creates tight coupling. The repository pattern abstracts database access. Agents call repository methods like `ProjectRepository.create()` and never touch SQLAlchemy sessions directly.

Create `app/core/repositories.py`:

```python
from sqlalchemy.orm import Session
from app.models.project import Project, ProjectStatus
from app.models.opportunity import OpportunityScore
from app.models.outline import Outline, Chapter
from app.models.manuscript import Manuscript, Section
from app.models.artifact import Artifact
import json


class ProjectRepository:
    @staticmethod
    def create(db: Session, project_id: str, title: str, niche: str, product_brief: str = None) -> Project:
        project = Project(
            id=project_id,
            title=title,
            niche=niche,
            product_brief=product_brief,
        )
        db.add(project)
        db.commit()
        db.refresh(project)
        return project

    @staticmethod
    def get(db: Session, project_id: str) -> Project:
        return db.query(Project).filter(Project.id == project_id).first()

    @staticmethod
    def update_status(db: Session, project_id: str, status: ProjectStatus) -> Project:
        project = ProjectRepository.get(db, project_id)
        if project:
            project.status = status
            db.commit()
            db.refresh(project)
        return project

    @staticmethod
    def update(db: Session, project_id: str, **kwargs) -> Project:
        project = ProjectRepository.get(db, project_id)
        if project:
            for key, value in kwargs.items():
                if hasattr(project, key):
                    setattr(project, key, value)
            db.commit()
            db.refresh(project)
        return project

    @staticmethod
    def list(db: Session, limit: int = 10) -> list[Project]:
        return db.query(Project).limit(limit).all()


class OpportunityRepository:
    @staticmethod
    def create(db: Session, project_id: str, **kwargs) -> OpportunityScore:
        score = OpportunityScore(project_id=project_id, **kwargs)
        db.add(score)
        db.commit()
        db.refresh(score)
        return score

    @staticmethod
    def get_by_project(db: Session, project_id: str) -> OpportunityScore:
        return db.query(OpportunityScore).filter(OpportunityScore.project_id == project_id).first()


class OutlineRepository:
    @staticmethod
    def create(db: Session, project_id: str, title: str, summary: str = None, estimated_word_count: int = None) -> Outline:
        outline = Outline(
            project_id=project_id,
            title=title,
            summary=summary,
            estimated_word_count=estimated_word_count,
        )
        db.add(outline)
        db.commit()
        db.refresh(outline)
        return outline

    @staticmethod
    def add_chapter(db: Session, outline_id: str, title: str, order: int, summary: str = None, estimated_word_count: int = None) -> Chapter:
        chapter = Chapter(
            outline_id=outline_id,
            title=title,
            summary=summary,
            order=order,
            estimated_word_count=estimated_word_count,
        )
        db.add(chapter)
        db.commit()
        db.refresh(chapter)
        return chapter

    @staticmethod
    def get_by_project(db: Session, project_id: str) -> Outline:
        return db.query(Outline).filter(Outline.project_id == project_id).first()


class ManuscriptRepository:
    @staticmethod
    def create(db: Session, project_id: str, title: str) -> Manuscript:
        manuscript = Manuscript(project_id=project_id, title=title)
        db.add(manuscript)
        db.commit()
        db.refresh(manuscript)
        return manuscript

    @staticmethod
    def add_section(db: Session, manuscript_id: str, title: str, order: int, content: str = None, chapter_id: str = None) -> Section:
        section = Section(
            manuscript_id=manuscript_id,
            title=title,
            order=order,
            content=content,
            chapter_id=chapter_id,
        )
        db.add(section)
        db.commit()
        db.refresh(section)
        return section

    @staticmethod
    def get_by_project(db: Session, project_id: str) -> Manuscript:
        return db.query(Manuscript).filter(Manuscript.project_id == project_id).first()


class ArtifactRepository:
    @staticmethod
    def create(db: Session, project_id: str, artifact_type: str, file_path: str = None, mime_type: str = None, metadata: dict = None) -> Artifact:
        artifact = Artifact(
            project_id=project_id,
            artifact_type=artifact_type,
            file_path=file_path,
            mime_type=mime_type,
            metadata_json=json.dumps(metadata) if metadata else None,
        )
        db.add(artifact)
        db.commit()
        db.refresh(artifact)
        return artifact

    @staticmethod
    def get_by_project_and_type(db: Session, project_id: str, artifact_type: str) -> Artifact:
        return db.query(Artifact).filter(
            Artifact.project_id == project_id,
            Artifact.artifact_type == artifact_type,
        ).first()

    @staticmethod
    def list_by_project(db: Session, project_id: str) -> list[Artifact]:
        return db.query(Artifact).filter(Artifact.project_id == project_id).all()
```

The repository layer has a clear contract. Each method takes a `Session` as its first argument, performs a single logical operation, and returns a model instance. Agents never call `db.add()` or `db.commit()` directly — they delegate to repositories.

## Alembic setup

Alembic manages database schema versions. It generates migration scripts when you change models and applies them in order.

If you haven’t already, initialise Alembic:

```bash
alembic init alembic
```

This creates an `alembic/` directory with `env.py`, `script.py.mako`, and `README`.

Edit `alembic.ini` to point at your database:

```ini
[alembic]
script_location = alembic
sqlalchemy.url = sqlite:///./data/app.db
```

For production, you’d use a dynamic URL from an environment variable. For development, a hardcoded SQLite path is fine.

Edit `alembic/env.py` to import your models. Find the line that says `target_metadata = None` and replace it with:

```python
from app.models import Base
target_metadata = Base.metadata
```

Also update the import section at the top of `env.py`:

```python
from logging.config import fileConfig
from sqlalchemy import engine_from_config, pool
from alembic import context
from app.models import Base
```

Generate the first migration:

```bash
alembic revision --autogenerate -m "Initial project models"
```

This inspects your models and generates a migration script in `alembic/versions/`.

Apply it:

```bash
alembic upgrade head
```

You should see output like `INFO  [alembic.runtime.migration] Context impl SQLiteImpl.`

Check that the tables exist:

```bash
python3 -c "from app.core.database import engine; print(engine.table_names())"
```

You should see: `projects`, `opportunity_scores`, `outlines`, `chapters`, `manuscripts`, `sections`, `artifacts`, and `alembic_version`.

## Test the database layer

Create `tests/test_database.py`:

```python
import os
import sys
import pytest

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from app.core.database import Base, engine, SessionLocal, get_db
from app.models.project import Project, ProjectStatus
from app.models.opportunity import OpportunityScore
from app.models.outline import Outline, Chapter
from app.models.manuscript import Manuscript, Section
from app.models.artifact import Artifact
from app.core.repositories import (
    ProjectRepository, OpportunityRepository,
    OutlineRepository, ManuscriptRepository, ArtifactRepository,
)


@pytest.fixture(autouse=True)
def setup_db():
    """Create tables before each test and drop after."""
    Base.metadata.create_all(bind=engine)
    yield
    Base.metadata.drop_all(bind=engine)


def test_create_project():
    db = SessionLocal()
    project = ProjectRepository.create(db, "proj-1", "Australian Gardening", "gardening", "A guide to native plants")
    assert project.id == "proj-1"
    assert project.status == ProjectStatus.briefed
    db.close()


def test_project_status_transitions():
    db = SessionLocal()
    project = ProjectRepository.create(db, "proj-2", "Test Book", "test")
    ProjectRepository.update_status(db, "proj-2", ProjectStatus.research_complete)
    updated = ProjectRepository.get(db, "proj-2")
    assert updated.status == ProjectStatus.research_complete
    db.close()


def test_opportunity_score():
    db = SessionLocal()
    ProjectRepository.create(db, "proj-3", "Test", "test")
    score = OpportunityRepository.create(db, "proj-3", demand_score=85, competition_score=40)
    assert score.demand_score == 85
    db.close()


def test_outline_and_chapters():
    db = SessionLocal()
    ProjectRepository.create(db, "proj-4", "Test", "test")
    outline = OutlineRepository.create(db, "proj-4", "Test Outline", "A summary", 5000)
    chapter = OutlineRepository.add_chapter(db, outline.id, "Chapter 1", 1, "First chapter", 2000)
    assert chapter.title == "Chapter 1"
    assert chapter.order == 1

def test_manuscript_and_sections():
    db = SessionLocal()
    ProjectRepository.create(db, "proj-5", "Test", "test")

    section = ManuscriptRepository.add_section(db, manuscript.id, "Section 1", 1, "Content here")
    assert section.content == "Content here"
    db.close()


def test_artifact():
    db = SessionLocal()
    ProjectRepository.create(db, "proj-6", "Test", "test")
    artifact = ArtifactRepository.create(db, "proj-6", "cover", "/path/to/cover.png", "image/png", {"style": "minimal"})

def test_list_projects():
    db = SessionLocal()
    ProjectRepository.create(db, "proj-a", "A", "a")
```

## Troubleshooting

**“alembic command not found”**
Alembic is installed as part of your dependencies. If you’re in a venv, make sure it’s activated. If you installed system-wide, it should be in your PATH.

**“No such table: projects”**
You forgot to run `alembic upgrade head`. Run it, or call `Base.metadata.create_all(bind=engine)` in a script to create tables directly.

**“SQLite database is locked”**
SQLite allows one writer at a time. If you’re running tests in parallel, switch to PostgreSQL or use `pytest -n 1` to serialise tests.

**“Foreign key constraint failed”**
You’re trying to create a child record before the parent exists. Always create the Project first, then attach OpportunityScore, Outline, and Manuscript to it.
