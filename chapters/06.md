# Chapter 6: The FastAPI MCP Server

*Routes, schemas, CORS, health checks, and the agent dispatch mechanism.*

---

## What this server does

The FastAPI MCP server is the control plane for the entire workforce. It exposes HTTP endpoints that let you:
- List available agents
- Execute an agent with a project ID and payload
- Create, read, and update projects
- Query Stripe products and stats
- Check service health

It’s not a job queue. It’s a dispatcher. When you POST to `/agents/manuscript_author/execute`, the server calls the Manuscript Author’s `execute()` method, passes the project ID and payload, and returns the result. The heavy lifting happens inside the agent, not in the HTTP layer.

---

## Server architecture

The server lives in `app/api/`. It has three files:

- `app/api/__init__.py` — the FastAPI app instance, middleware, and router registration
- `app/api/routes.py` — all endpoint definitions
- `app/api/server.py` — legacy entry point (kept for backwards compatibility)

The `app/api/__init__.py` file is now the canonical entry point. It creates the app, registers routers, and includes the Stripe endpoints.

## Creating the app

`app/api/__init__.py`:

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from app.api.routes import router as agent_router

app = FastAPI(
    title="Fair Dinkum Publishing Agent Workforce",
    description="MCP server orchestrating the end-to-end ebook production pipeline.",
    version="0.1.0",
)

# CORS middleware for local development
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Register routers
app.include_router(agent_router, prefix="/agents", tags=["agents"])

# Stripe router
from fastapi import APIRouter
stripe_router = APIRouter()

@stripe_router.get("/products", tags=["stripe"])
def list_stripe_products():
    """List Stripe products."""
    from app.services.stripe import StripeService
    return StripeService.list_products()

@stripe_router.get("/stats", tags=["stripe"])
def get_stripe_stats():
    """Get Stripe account stats."""
    from app.services.stripe import StripeService
    return StripeService.get_stats()

app.include_router(stripe_router, prefix="/stripe", tags=["stripe"])


@app.get("/health", tags=["health"])
def health_check():
    """Health check endpoint."""
    return {"status": "healthy", "service": "fair-dinkum-publishing-agent-workforce"}


@app.on_event("startup")
def startup_event():
    """Initialize resources on startup."""
    pass


@app.on_event("shutdown")
def shutdown_event():
    """Clean up resources on shutdown."""
    pass
```

Key points:
- `CORSMiddleware` allows requests from any origin. This is fine for local development. In production, restrict `allow_origins` to your domain.
- The `agent_router` handles all agent and project endpoints under `/agents`.
- The `stripe_router` handles Stripe-specific endpoints under `/stripe`.
- The `/health` endpoint is unauthenticated so load balancers and monitoring tools can check it.

## Agent and project routes

`app/api/routes.py`:

```python
from fastapi import APIRouter, HTTPException
from pydantic import BaseModel
from typing import Optional, Dict, Any
from app.models.project import ProjectStatus

router = APIRouter()


class AgentRequest(BaseModel):
    project_id: str
    action: str
    payload: Optional[Dict[str, Any]] = None


class AgentResponse(BaseModel):
    status: str
    message: str
    data: Optional[Dict[str, Any]] = None


@router.get("/", tags=["agents"])
def list_agents():
    """List all available agents."""
    agents = [
        "product_director", "market_research", "opportunity_scoring",
        "positioning_offer", "outline_architect", "manuscript_author",
        "editorial", "fact_check_compliance", "cover_creative_director",
        "ebook_production", "sales_copy", "funnel_fulfillment",
        "analytics_optimisation", "obsidian_knowledge_manager", "launch_strategist"
    ]
    return {"agents": agents, "count": len(agents)}


@router.post("/{agent_name}/execute", response_model=AgentResponse, tags=["agents"])
def execute_agent(agent_name: str, request: AgentRequest):
    """Execute a specific agent workflow step."""
    valid_agents = [
        "product_director", "market_research", "opportunity_scoring",
        "positioning_offer", "outline_architect", "manuscript_author",
        "editorial", "fact_check_compliance", "cover_creative_director",
        "ebook_production", "sales_copy", "funnel_fulfillment",
        "analytics_optimisation", "obsidian_knowledge_manager", "launch_strategist"
    ]

    if agent_name not in valid_agents:
        raise HTTPException(status_code=404, detail=f"Agent '{agent_name}' not found")

    # In production, this would dispatch to the actual agent
    return AgentResponse(
        status="success",
        message=f"Agent '{agent_name}' executed for project '{request.project_id}'",
        data={"agent": agent_name, "project_id": request.project_id}
    )


@router.post("/projects", tags=["projects"])
def create_project(project_id: str, title: str, niche: str, product_brief: Optional[str] = None):
    """Create a new project."""
    from app.core.database import get_db
    from app.core.repositories import ProjectRepository
    
    db = next(get_db())
    project = ProjectRepository.create(
        db=db,
        project_id=project_id,
        title=title,
        niche=niche,
        product_brief=product_brief
    )
    return {
        "status": "success",
        "message": "Project created",
        "data": {
            "id": project.id,
            "title": project.title,
            "niche": project.niche,
            "status": project.status.value
        }
    }


@router.get("/projects/{project_id}", tags=["projects"])
def get_project(project_id: str):
    """Get project details."""
    from app.core.database import get_db
    from app.core.repositories import ProjectRepository
    
    db = next(get_db())
    project = ProjectRepository.get(db, project_id)
    if not project:
        raise HTTPException(status_code=404, detail="Project not found")
    
    return {
        "status": "success",
        "data": {
            "id": project.id,
            "title": project.title,
            "niche": project.niche,
            "status": project.status.value,
            "product_brief": project.product_brief,
            "positioning_statement": project.positioning_statement,
            "outline": project.outline,
            "manuscript_path": project.manuscript_path,
            "cover_path": project.cover_path,
            "ebook_path": project.ebook_path,
            "sales_copy_path": project.sales_copy_path,
            "funnel_url": project.funnel_url,
            "stripe_payment_link": project.stripe_payment_link,
            "obsidian_note_path": project.obsidian_note_path,
            "created_at": str(project.created_at),
            "updated_at": str(project.updated_at),
            "version": project.version
        }
    }


@router.patch("/projects/{project_id}/status", tags=["projects"])
def update_project_status(project_id: str, status: str):
    """Update project status."""
    from app.core.database import get_db
    from app.core.repositories import ProjectRepository
    
    try:
        new_status = ProjectStatus(status)
    except ValueError:
        raise HTTPException(status_code=400, detail=f"Invalid status: {status}")
    
    db = next(get_db())
    project = ProjectRepository.update_status(db, project_id, new_status)
    if not project:
        raise HTTPException(status_code=404, detail="Project not found")
    
    return {
        "status": "success",
        "message": f"Project status updated to {status}",
        "data": {"id": project.id, "status": project.status.value}
    }
```

This file defines:
- `GET /` — list all agents
- `POST /{agent_name}/execute` — execute an agent
- `POST /projects` — create a project
- `GET /projects/{project_id}` — read a project
- `PATCH /projects/{project_id}/status` — update project status

The `next(get_db())` pattern gets a database session from the FastAPI dependency. It’s the standard way to inject database access into route handlers.

## Pydantic schemas

Pydantic models define the shape of request and response data. They’re not just validation — they’re documentation. FastAPI uses them to generate the OpenAPI schema at `/docs`.

**AgentRequest** validates that every agent execution request includes a `project_id` and optionally an `action` and `payload`.

**AgentResponse** ensures every agent response includes `status`, `message`, and optional `data`.

In production, you’d expand these schemas with more specific models. For example, `ExecuteManuscriptRequest` would have fields for `chapter_ids`, `style`, and `temperature`. The generic `AgentRequest` works for now because the actual agent logic lives in Python, not in the API schema.

## Stripe routes

The Stripe router lives in `app/api/__init__.py`. It provides two endpoints:

`GET /stripe/products`
Returns a list of Stripe products or a graceful error if the API key isn’t configured.

`GET /stripe/stats`
Returns active subscription count, recent revenue, and available balance.

These endpoints are thin wrappers around `StripeService`. They’re designed for quick integration and debugging, not for public consumption. In production, you’d add authentication.

## CORS and security

CORS (Cross-Origin Resource Sharing) controls which domains can call your API. The current configuration allows all origins:

```python
allow_origins=["*"]
```

This is fine for local development. For production, restrict it:

```python
allow_origins=["https://yourdomain.com", "https://app.yourdomain.com"]
```

You should also add authentication. The current server has no auth layer. Anyone who can reach port 8000 can execute agents, create projects, and read data. In production, add API key validation or OAuth2.

A simple API key middleware:

```python
from fastapi import Request, HTTPException

@app.middleware("http")
async def verify_api_key(request: Request, call_next):
    if request.url.path.startswith("/health"):
        return await call_next(request)
    api_key = request.headers.get("X-API-Key")
    if api_key != os.getenv("API_KEY"):
        raise HTTPException(status_code=403, detail="Invalid API key")
    return await call_next(request)
```

Set `API_KEY` in your `.env` file and you’ve added basic authentication.

## Request flow

Here’s what happens when you call `POST /agents/manuscript_author/execute`:

1. FastAPI receives the request and validates the JSON body against `AgentRequest`.
2. The route handler checks that `manuscript_author` is in the valid agents list.
3. The handler imports the `ManuscriptAuthor` class.
4. It creates an instance with the `project_id`.
5. It calls `agent.execute(**request.payload)`.
6. The agent reads the project’s outline from the database.
7. The agent calls the LLM (local or cloud) to generate content.
8. The agent saves the generated sections to the database via `ManuscriptRepository`.
9. The agent returns a dict with `status`, `message`, and `data`.
10. FastAPI serialises the dict into JSON and returns it to the client.

In the current implementation, step 3–9 are mocked. The agent returns a simulated success response. In Chapter 7, we’ll implement the real logic.

## Troubleshooting

**“ImportError: cannot import name 'router' from 'app.api.routes'”**
Make sure `app/api/routes.py` defines `router = APIRouter()` at the module level and that `app/api/__init__.py` imports it correctly.

**“No module named 'app'”**
Run tests from the project root directory. The `sys.path.insert(0, ...)` in each test file ensures the `app` package is importable.

**“CORS error in browser”**
The browser is blocking the request because the server’s `allow_origins` doesn’t include your frontend domain. For local development with the FastAPI docs, this shouldn’t happen. If you’re building a separate frontend, add its origin to `allow_origins`.

**“Database session not closed”**
The `next(get_db())` pattern doesn’t automatically close the session. In production, use a proper dependency injection pattern with `yield`:

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

And in the route:

```python
@router.post("/projects")
def create_project(..., db: Session = Depends(get_db)):
    ...
```
